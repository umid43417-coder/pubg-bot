# 🎮 PUBG Savdo Bot + Mini App

Telegram bot va WebApp (mini app) — PUBG akkauntlari magazini. Savdo admin (garant) orqali.

## Imkoniyatlar
- ➕ Akkaunt sotish: video/rasm + LVL, RP, kiyimlar, skinlar, dostijeniya, titullar, prokachka, kill chat, narx
- 🛒 Mini app magazin: qidiruv, saralash, media galereya, gamer dizayn (jonli animatsiyalar)
- ✅ Admin moderatsiya: har bir e'lon tasdiqlanadi
- 🛡 Sotib olish so'rovi to'g'ridan-to'g'ri adminga tushadi (garant)

## ENV
| Nomi | Tavsif |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather tokeni |
| `ADMIN_ID` | Admin Telegram ID |
| `WEBAPP_URL` | Railway public URL (https://...) |
| `DATA_DIR` | (ixtiyoriy) ma'lumot papkasi, default `./data` |

## Ishga tushirish
```bash
npm install
npm start
```
